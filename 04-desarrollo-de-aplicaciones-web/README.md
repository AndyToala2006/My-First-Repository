# 04 · Desarrollo de Aplicaciones Web

Desarrollo web **frontend** con HTML, CSS y JavaScript, evolucionando semana a
semana hacia sitios más completos e interactivos.

## 🧰 Tecnologías
- HTML5
- CSS3
- JavaScript

## 📅 Trabajos por semana
| Semana | Tema |
|--------|------|
| 2 | Estructura básica HTML |
| 3 | Estilos CSS y manejo de recursos (imágenes, video) |
| 4 | Sitio multipágina (IA, Nube, Seguridad) — trabajo en grupo |
| 5–8 | Interactividad con JavaScript |

## 🔗 Proyecto backend relacionado
El proyecto **[Sistema de Facturación con Flask](../Sistema_Facturacion_Flask/)**
(backend en Python) forma parte de esta línea de desarrollo web y está
desplegado en Render.

## ▶️ Cómo ver
Abre cualquier `index.html` en el navegador (doble clic o *Live Server*).
