# 06 · Aplicaciones Móviles

> 🚧 **Asignatura en curso.** Esta carpeta está lista para recibir las prácticas
> y proyectos de Desarrollo de Aplicaciones Móviles.

## 🧰 Tecnología (por definir)
Cuando el docente confirme las herramientas del curso, actualiza esta sección.
Las opciones más comunes son:

| Stack | Lenguaje | Notas |
|-------|----------|-------|
| **Android nativo** | Kotlin / Java | Android Studio |
| **Flutter** | Dart | Multiplataforma (Android + iOS) |
| **React Native** | JavaScript / TypeScript | Multiplataforma |

## 📁 Organización sugerida
Crea una subcarpeta por semana o por proyecto, igual que en el resto del
repositorio:

```
06-aplicaciones-moviles/
├── semana-01-introduccion/
├── semana-02-.../
└── proyecto-final/
```

## ✅ Recomendaciones
- Añade un `.gitignore` propio del framework (ej. el de Android o Flutter) para
  no subir carpetas de compilación (`build/`, `.gradle/`, `*.apk`, etc.).
- Documenta cada práctica con un breve README o comentarios en el código.
