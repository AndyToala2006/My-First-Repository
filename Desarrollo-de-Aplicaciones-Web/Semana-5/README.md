# Galería Interactiva con JavaScript

Proyecto académico donde se desarrolla una galería de imágenes interactiva
utilizando HTML, CSS y JavaScript.

## Funcionalidades
- Agregar imágenes mediante URL
- Seleccionar imágenes con un clic
- Eliminar la imagen seleccionada
- Atajo de teclado (Delete)

## Tecnologías
- HTML
- CSS (Grid)
- JavaScript (DOM y eventos)

## Publicación
El proyecto fue publicado mediante GitHub.
